## Summary
`src/mdqm/adapters/oracle.py` is the Oracle `SourceAdapter` in thin mode (`oracledb`, no Oracle client):
a pooled connection with a read-only session, `extract_catalog` from the data dictionary,
`extract_partitions` reading the **interval** partitions D05's loader produced, `execute` returning an
`ArrowStream` of `pyarrow.RecordBatch` with the row cap honoured, `cancel`, and `NotSupported` with the
capability names from `OPTIONAL_METHODS` for what it does not serve. It is registered through the
`mdqm.adapters` entry point (additive to `pyproject.toml`).

## Evidence (executed against the live Oracle Free container)
- 74 unit tests pass with a fake driver; 18 of 19 integration tests pass against the real server.
- `run_conformance` passes against this adapter.
- The catalog finds the billing tables and the interval partitions with real bounds.
- `max_rows` truncates exactly; a write is refused by the read-only session with Oracle's own error.

## One acceptance item is NOT proven: the timeout
With a 1 s `call_timeout` the thin driver reports **DPY-4011 (the database or network closed the
connection)** rather than DPY-4024, so the adapter raises `DatabaseError` and the pooled connection is
gone -- the opposite of "the deadline fires and the session survives". The test is marked
`xfail(strict=True)` so it fails loudly the day somebody fixes it and forgets to flip the marker.

Two candidate fixes, both code decisions rather than test details: map DPY-4011 to `OracleTimeout`
(and drop the dead connection from the pool), or use the driver's interrupt/`cancel()` path with a
client-side deadline. This is why the row is `partial`, not `done`.

## Calibration note
The first version of the test used `CONNECT BY level <= 2000000` as the slow statement; on this
hardware it finishes inside the deadline, and raising the level to make it slower hit `ORA-30009 (not
enough memory)`. A sleeping statement (`DBMS_SESSION.SLEEP(5)`) is the right shape: it burns server
time without CPU or memory, so only the deadline can end it.
