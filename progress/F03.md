## Summary
Built `mdqm.config` as four small modules. `settings.py` holds the pydantic-settings `Settings`
(server bind, paths for metadata DB / semantic dir / cache dir, model endpoint, SMTP, limits, quiet
windows, sources) loaded from `MDQM_*` env vars and an optional `mdqm.yaml` via a custom
ruamel.yaml settings source, with constructor > env > file > defaults priority. `Settings.load()` wraps
pydantic `ValidationError` into `ConfigError(source, problems)` that names the file and the dotted key
path and never the offending value. `SourceConfig` carries name/adapter/secret-ref/load limits/auth/
rate-limit/adapter options, with a duplicate-name check and both mapping and list YAML forms.
`quiet.py` holds `QuietWindow` (tz + start/end, cross-midnight aware) and `secrets.py` the
`SecretProvider` Protocol with `EnvSecretProvider` and `FileSecretProvider`. Credentials are `SecretStr`
on `Settings`, are rejected in YAML before validation (with a pointer to `secret: <name>`), and are
proved absent from `repr`, `str`, `model_dump_json`, `ConfigError` and `SecretNotFound`.
## Decisions
- **YAML is the lowest source above defaults.** Implemented as `_YamlSettingsSource` in
  `settings_customise_sources` with the file path carried in a `ContextVar` (not a module global or a
  mutated `model_config`), so two loads in different threads cannot see each other's file.
- **Literal-credential rejection happens before pydantic runs**, by walking the parsed YAML for key
  names in `CREDENTIAL_KEYS` (`password`, `passwd`, `pwd`, `api_key`, `apikey`, `token`,
  `access_token`, `auth_token`, `refresh_token`, `client_secret`, `secret_key`, `access_key`).
  `secret` is deliberately absent: it is our reference field. Empty/None values are allowed (nothing
  to leak), and the path includes list indices (`sources[0].options.token`). A source-level literal
  gets the `secret: <name>` hint the acceptance item asks for; the same hint is used elsewhere plus
  the environment-variable route.
- **`ConfigError` reports only `loc` + `msg` from pydantic**, never `input`: pydantic records the
  offending input, which for a whole-document validation error can be the entire mapping. The YAML
  error path also uses `raise ... from None` because ruamel echoes the offending source line in its
  message.
- **Broken YAML reports position and problem text**, not the file snippet (`MarkedYAMLError.problem`
  plus `problem_mark`), for the same reason.
- **No quiet window configured means "not restricted"**: `Settings.is_quiet(now)` returns True for an
  empty `quiet_windows` list. The safe-for-a-laptop reading; a deployment that wants to protect the
  primaries configures windows. A zero-length window (`start == end`) is never quiet, the safe reading
  for the opposite case.
- **Naive `now` is read as wall-clock time in the window's zone**, aware `now` is converted to it.
  Documented on `is_quiet`, so a caller cannot silently get UTC semantics.
- **Secret resolution is not eager.** `Settings.secret_provider()` returns a `FileSecretProvider` when
  `secrets.dir` is set (the Docker/Kubernetes mount shape in DESIGN section 14), else an
  `EnvSecretProvider` with prefix `MDQM_SECRET_`. Adapters resolve a reference at connect time; no
  secret value is ever stored on `Settings`.
- **Secret reference names are validated** (`^[A-Za-z0-9][A-Za-z0-9_.-]*$`), which keeps a reference
  from being usable as a path traversal, a URL, or a shell fragment. `EnvSecretProvider` maps the
  reference to `PREFIX + upper(name) with non-alphanumerics -> '_'` and refuses names it cannot map
  faithfully.
- **Defaults, all conservative**: bind `127.0.0.1:8765`, `max_rows=1000`, `max_concurrency=8`,
  `per_source_concurrency=3`, `query_timeout_s=60`, `max_partitions_scanned=8`, model retries 2.
  Empty `model.base_url` means "must be configured"; `smtp.enabled` is `bool(host)`.
## Deviations
No design change, so `docs/DESIGN.md` is untouched. The design only says "config via env + a volume",
which this implements. One addition the design does not spell out: `mdqm.yaml` may also list `sources`
as a mapping (`sources: {crm: {...}}`), matching the style of `examples/semantic_example.yaml`; the
canonical list form stays the model.
