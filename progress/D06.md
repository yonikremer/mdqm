(`CREATE PARTITION FUNCTION ... RANGE RIGHT FOR VALUES (...)`, `CREATE PARTITION SCHEME ... ALL TO
([PRIMARY])`), so the partition tuples are the server's own rather than a range declaration in a
`CREATE TABLE`.
