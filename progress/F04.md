## Summary

The adapter seam every source plugs into:

- `src/mdqm/adapters/base.py`: `SourceAdapter` Protocol exactly as `docs/DESIGN.md` "Adapter interface" (required
  `kind`, `dialect`, `probe`, `extract_catalog`, `execute`, `cancel`; optional `extract_partitions`, `explain`,
  `mine_queries`, `mutability_stats`), `NotSupported(capability, detail)`, the `OPTIONAL_METHODS` method→capability
  table (one place, so the probe and the conformance kit cannot disagree), the `ArrowStream` result protocol,
  `AdapterFactory` and the `supports_method` helper for optional methods that are simply absent.
- `src/mdqm/adapters/registry.py`: `AdapterRegistry` discovers the entry-point group `mdqm.adapters` through
  `importlib.metadata`, accepts explicit `register(kind, factory)` for tests, refuses duplicates, validates the
  required methods at registration (classes/factory objects) and again at creation, and builds an adapter from a
  `SourceConfig` while checking the kind agrees.
- `src/mdqm/testing/conformance.py`: `run_conformance(adapter_factory, *, fragment, limits, slow_fragment, grace_s)`
  — probe returns `Capabilities` (adapter name must match), catalog is non-empty, execute honours `max_rows` and
  raises at `timeout_s`, cancel is idempotent and cannot emit extra rows, and each optional method either returns
  the promised model or raises `NotSupported` (absent method + probe claiming support = failure).
- `tests/unit/test_registry.py`: entry-point discovery with `importlib.metadata` doubles (no install), five
  parametrized "missing required method" cases, duplicate/unknown/no-arg errors, `NotSupported`↔capability,
  and the conformance kit run against one compliant fake plus nine deliberately broken ones.

## Decisions

- `ArrowStream` is a `Protocol` (`schema`, `__iter__` of `pyarrow.RecordBatch`, `close`) defined here: DESIGN names the
  type but F02 did not model it, and it has to stream lazily so the governor can stop at `max_rows` and `cancel` has
  something to interrupt. `pyarrow` ships no `py.typed` marker (checked on the pinned 26.0.1), so `pyproject.toml`
  gains a `[[tool.mypy.overrides]]` block for `pyarrow`/`pyarrow.*` — otherwise strict mode rejects every annotation
  naming an Arrow type.
- Factory contract is `factory(config: SourceConfig, secrets: SecretProvider | None) -> SourceAdapter`; the registry
  owns the secret provider and hands it over, adapters decide when to connect. `SourceConfig.adapter` is the registry
  key and must equal the built adapter's `kind` (checked; a mismatch is a plugin bug, not a runtime surprise).
- Required-method validation runs on classes/factory objects at `register()` (inspectable without calling) and on the
  instance at `create()`; a lambda/partial is only checkable after it is called, so `create()` covers that case.
- `discover()` skips kinds already registered instead of raising: re-probing after an explicit registration must not
  explode. A duplicate explicit `register()` still raises — import order must never decide which plugin wins.
- `NotSupported` is a normal answer (carries the capability name), never logged as an error; the conformance kit
  requires "the probe does not claim support" rather than "the probe says False", because `Capability.supported` is
  tri-state on purpose and `unknown` also triggers the fallback.
- Conformance kit imports no test framework (it lives in `src`, and `pytest` is a dev extra): failures are plain
  `AssertionError` with an `adapter conformance:` prefix. Default fragment is `SELECT 1 AS one`; a `dsl`-dialect
  adapter must pass `fragment=`, and the kit fails loudly instead of skipping. The timeout proof is opt-in via
  `slow_fragment=` (a query can only be made slow by the adapter's owner), with a 10 s default grace.
- No `mdqm.adapters` entry point is declared in `pyproject.toml` yet: the reusable in-memory adapter is task D03's
  file (`src/mdqm/testing/fake_adapter.py`), and a declared entry point to a module that does not exist would break
  every discovery. The fake used by these tests is a test double inside `tests/unit/test_registry.py`.
