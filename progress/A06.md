## Summary

A real `SourceAdapter` over an OpenAPI 3.x-described HTTP API (`src/mdqm/adapters/openapi.py`,
`kind="openapi"`, `dialect()="dsl"`). It reads the spec with a small in-house reader (no
`openapi-core`/`prance` dependency): every `GET` **collection** becomes a virtual table, the array
item schema gives its columns, and the declared query parameters become `Index` entries (the
"filterable columns" the planner reasons about). Paging style (cursor / offset / page / none) is
detected from the declared parameters plus the envelope's next-token key. `execute` turns a
fragment's `{"table", "params"}` request into GET requests, follows pages, enforces `max_rows`
itself and honours the deadline between pages; a TTL cache plus a per-key lock means a repeated or
concurrent identical call costs zero HTTP requests. Read-only is enforced three ways: no code path
builds a non-GET request, `GetOnlyTransport` refuses any other method at the transport layer, and a
mutating operation in the spec never becomes a table (it is listed in `ignored_operations`).
401/403, a missing secret, a 429 and a spent local budget all become agent-facing `ErrorResponse`
values carried on `OpenApiError`, never driver text. Registered through the `mdqm.adapters`
entry-point group and it passes `run_conformance`.

## Decisions

- **A table is a GET collection with no path parameters and an array response.** A path parameter
  means the caller substitutes a value (a lookup, not a set) and a non-array answer is one object.
  Both are reported in `OpenApiAdapter.ignored_operations` rather than silently dropped, so
  "everything reported, nothing silent" holds. On the mock this yields exactly `rates` and reports
  `/customers/{id}/score`, `/health`, `/slow`, `/_stats` as ignored.
- **The fragment shape is `{"table": ..., "params": {...}}` in `Fragment.request`.** No compiler for
  API sources exists yet in this lane, so this is the documented contract this adapter reads and
  what `OpenApiAdapter.fragment(table, **params)` builds for the conformance kit.
- **An undeclared query parameter is refused (`INVALID_SPEC`) before any request.** Only spec-declared
  filters can reach the source; this is both a safety property and what keeps the URL from being
  built out of agent input.
- **The cache is in-memory, per adapter instance, with an injected clock.** Default TTL 60 s
  (conservative: an API is a live source; `fresh` bypassed it in a later lane), `cache_ttl_s=0`
  disables it. Cache hits carry `fetched_at` and `cached=True` on the stream so a caller can report
  provenance (principle 10).
- **Single-flight is a per-key `threading.Lock`, not `mdqm.cache.singleflight`.** That module's
  `SingleFlight` is `asyncio`-bound (it holds `asyncio.Task` objects), and adapters are synchronous
  by convention (`AGENTS.md` section 3). Same promise, blocking shape; documented in the docstring.
- **`OpenApiUnavailable` subclasses both `OpenApiError` and `OSError`,** so a caller that only knows
  the generic `mdqm.errors.from_exception` mapping still classifies a dead source as
  `SOURCE_UNAVAILABLE` rather than `INTERNAL_ERROR`.
- **`AnyHttpUrl` server URLs / `base_url` required:** a spec whose `servers[0].url` is relative and
  no `options.base_url` gives a clear config error at construction, not a confusing request failure.
- **The rate limiter is injected, not constructed.** The governor owns the shared limiter (A05); this
  adapter consults `acquire()` before each request, turns a denial into `QUOTA_EXCEEDED` without
  sending anything, and calls `report_429` with the parsed `Retry-After` when the API says 429.

## Not verified

- No live behaviour against a **real internal API**: none is reachable from this machine and there is
  no container runtime. Everything is verified against the D04 in-process mock through
  `httpx.ASGITransport`, which is the real FastAPI app, real spec, real auth, real 429 path.
- The offset and page paging styles are covered by unit tests over synthetic specs only; the mock
  serves cursor paging, so those two styles have no end-to-end HTTP path exercised here.
- Real-world spec quirks beyond the mock (nested `$ref` cycles, `allOf` composition, non-JSON
  success media types) are not covered; the reader raises a clear `_SpecError` for what it does not
  understand rather than guessing.
